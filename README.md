# 剧本角色测试 Story Role Quiz

一个纯前端、手机优先的互动角色测试：28 道生活剧情选择，通过 5 个维度匹配 16 种剧本角色，并生成适合小红书分享的结果卡。v0.2 增加关系线、压力线、冲突线、退场线等题目，并扩展结果报告。

## 当前角色

白切黑女二、清醒恶女、黑马、最后赢家、幕后玩家、隐藏王牌、白月光、意难平、局外人、恋爱军师、气氛组、一身反骨、不按剧本、半路杀出、嘴硬心软、压轴。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

构建产物位于 `dist/`，可直接部署到 Cloudflare Pages。

## 说明

这是娱乐型互动角色测试，不用于心理诊断或专业人格评估。

本项目的初始工程结构参考了 `ryan-flow/arknights-personality-v2`；本仓库已移除原项目的角色 IP、图片、剧情内容、题目和结果文案，仅保留并重新实现通用的前端测试产品思路。第三方来源说明见 `THIRD_PARTY_NOTICES.md`。
